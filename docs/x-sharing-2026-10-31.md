# ホーム・結果からXへ共有

ホームと結果の共有リンクを黒地・白文字の「Xでシェアする」に統一する。端末の共有メニューや共有文のコピーではなく、Xの投稿画面を新しいタブで開く。投稿の確定は利用者がX上で行う。

日本語のホーム共有文は、利用者の確認回答「20問に合わせる」に従って次の3行とする。

```text
イロアテ
文字の「色」か「意味」を20問当てるタイムアタック！
https://chameleonjp-lab.github.io/iroate/
```

結果では同じ紹介文に最終タイムと従来の初回/ベスト、またはクリアタイム/ミス/ペナルティを添える。リタイアはその状態を共有する。名前、サーバーのエラーメッセージ、他人のランキング行は含めない。ゲーム自体の問題数・判定・保存値・匿名回数・初期SE ONは変更しない。

Xの[公式Web Intent仕様](https://docs.x.com/x-for-websites/web-intents/overview)にある `https://x.com/intent/tweet` を使用し、textクエリ1項目へUnicode・改行・正式URLをエンコードする。リンクはtarget=_blankとrel=noopener noreferrerを使用する。ネイティブ共有APIの有無によらずXへ進む。診断エラーのコピーは従来どおり残す。

リンクは初期化・言語変更・結果表示時に更新する。ランキングの登録成功応答を検証した時点でも更新し、クリック直前にも更新する。これにより右クリック・中クリック・リンクのコピーでも最新の確定記録を扱う。未承認のランキング応答を共有文の初回/ベストとして使わない。

15言語のUIと共有文を用意し、紹介文の問題数はTOTAL_QUESTIONSを使う。日本語の厳密な文面、黒/白、ホーム/結果からXのpopupへ進むこと、通常クリック前の確定記録、送信失敗/リタイア/言語変更、共有メニュー未使用をChromium/WebKitで確認する。Xへのリクエストはpopupの初回要求を含めすべてmockし、X投稿・本番スコア・開始記録の書込みは行わない。実機SafariとXログイン後の実投稿は未試験。

実装前には旧ボタン名で失敗すること、登録応答後も古いhrefが残る問題を独立レビューで指摘し、回帰試験で再現した。最終結果と修正後の検証はPR本文/CIを参照する。

利用者がmainへマージすると既存Actionsが全検査後に自動配備する。PR段階では公開しない。開始mainはf4847ac0926c9cac90bd7fb66021e4f6402f3ec8（PR #4の利用者マージ済み版）。本番DBや実験場の登録行は変更しない。

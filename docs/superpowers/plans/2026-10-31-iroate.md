# Iroate Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 15言語、短いSE、テストで保護したGitHub Pages公開候補をPRにする。
**Architecture:** 既存生成をjs/engine.jsへ抽出、js/game.jsがUI制御。言語/音は独立モジュール。
**Tech Stack:** HTML/CSS/ES modules, Web Audio, Node test runner, Playwright Chromium/WebKit, GitHub Actions。
**Spec:** ../specs/2026-10-31-iroate-design.md

## Global Constraints

- 全20問、意味10/色10、誤答+5秒、正解まで同問、scale=100。
- game_slug=iroate、client_version=iroate-ranking-v1、既存RPC/保存構造維持。
- 本番書込試験なし、他ゲーム変更なし、main push/勝手なマージなし。
- 新版公開確認まで実験場PR/本番URL切替なし。

## Review Focus

- 未知言語/翻訳欠落/storage拒否でも起動しスコア同一。
- 長い色名が320px縦/横でも読め、切替は判定を変更しない。
- resume拒否・中断・急なOFFでも回答/時計は進む。
- 通信停止・再戦中の旧応答・エラーへの個人情報混入。
- 旧Pages設定のままテストを迂回しないこと。

# Xへの共有

Goal: ホームと結果の共有を、黒地・白文字の「Xでシェアする」リンクに統一する。

Spec: 利用者指定の3行をホームへ適用。確認回答により文言は「20問」とし、プレイ仕様は変更しない。結果は紹介文に従来の記録を添える。15言語のUI/共有文を維持する。

Design: X公式Web Intentの `https://x.com/intent/tweet?text=...` を使う。通常のa要素とtarget=_blank/rel=noopener noreferrerで遷移し、Xの投稿確定は利用者が行う。URLエンコードのみ小さな独立moduleに分離。native share/共有文のclipboard fallbackは廃止し、診断エラーのコピーは維持する。
